BEFORE YOUR FIRST SHOT

从下载，到第一杆

安装、系统选择与操作问题，放在这里一次说明。

Mac 版怎么安装？为什么要下载 DMG？
  1. 打开 Mac 的“关于本机”，查看“芯片”或“处理器”。Apple M 系列选择 arm64.dmg，Intel 处理器选择 x86_64.dmg。
  2. 双击 DMG，把 Desktop Icon Billiards.app 拖入旁边的 Applications（应用程序） 文件夹。
  3. 复制完成后弹出安装盘，从“应用程序”启动。系统询问桌面文件夹权限时，允许读取才能显示桌面图标。

请选择 .dmg 安装盘，不要把 GitHub 源码 ZIP 当作安装包。测试版未完成 Apple 公证；出现安全提示时，可在核实来源后参考 Apple 官方说明 ↗，不需要关闭系统整体安全保护。

Windows 与 Mac 的功能一样吗？

两个版本都有桌面图标球、鼠标蓄力、四种本机玩法、球杆皮肤、音效和暂停隐藏。Windows 版另外提供联网排行榜、成绩卡片与更新检查；Mac 目前为测试版，这三项尚未移植。页面中的游戏截图为 Windows 版。

会移动或删除电脑上的桌面文件吗？

不会。游戏读取桌面项目的图标，并在游戏层绘制和模拟台球运动；击球和进袋不会移动、删除桌面原文件。

怎么蓄力击球、暂停和隐藏？

在游戏中移动鼠标调整方向，按住左键蓄力，松开出杆。F1 暂停并隐藏，再按恢复。Mac 若把 F1 作为亮度键使用，按 fn + F1；也可使用菜单栏的台球控件。

下载地址变了吗？为什么要跳转夸克网盘？

地址没有变，Windows 与 Mac 按钮均进入同一个原有夸克网盘分享。官网记录下载入口的点击次数，不把点击数当作已安装人数。请在网盘内按系统和芯片选择对应安装包。

Mac 版没有图标、没有联网排名怎么办？

先检查 Finder 桌面是否有可见项目，以及系统是否允许应用读取桌面文件夹。Mac 测试版暂未提供联网排行榜，这不是账号或网络故障；可先使用本机玩法。桌面层级、跨应用焦点、多显示器与全局快捷键仍需更多实机验证。
