## 已验证的独立修正

`ShellDesktop._invoke` 原先通过 `ctypes.cast` 重解释拥有 COM 引用的指针，形成 `_objects` 引用环。真实 Windows Shell 图标读取实验确认：原实现的三个图标工厂均延迟到工作线程 `CoUninitialize` 之后才释放；修正后均在该线程关闭 COM 环境前释放。

调用改为借用数值地址，保留调用期间的原对象所有权。原实现会被新增的引用环检查检出；修正后的三个检查通过，包括实际 Shell 图标读取、所属线程释放时机与 HRESULT 错误传播。

这是一处已验证的资源生命周期缺陷；尚无原生线程栈证明它对应此前所有无响应记录，不将其描述为已经证明解决所有闪退。
